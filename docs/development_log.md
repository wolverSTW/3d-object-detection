# Development Log

## Project Initialization

This project was initialized as a thesis-ready scaffold for a YOLOv10-based 3D object detection and distance estimation pipeline on KITTI.

## Planned Workflow

1. Data acquisition and integrity validation
2. Exploratory data analysis and annotation audit
3. Geometry-aware preprocessing and target generation
4. Baseline YOLOv10 3D detection model
5. Geometry-guided model extension
6. Training and validation loops
7. Evaluation and ablation analysis
8. Reporting and thesis write-up

## Notes

- The repository structure is designed to align with the proposed MSc thesis pipeline.
- Mock data generation is supported for local development and unit testing.
- Real KITTI data can be placed under `data/KITTI/raw/` to replace the mock dataset.
